3. Key concepts at a glance

VNet

Private network address space and connectivity boundary.

Subnet

Logical segment of a VNet address range.

NIC

VM's virtual network interface, with IP configuration and MAC address.

Public IP

Globally routable address for supported public-facing connectivity.

Private IP

Address used within private network communication.

NSG

Filters inbound and outbound traffic using security rules.

Route Table

Resource that stores routes.

UDR

Custom route that influences the next hop.
